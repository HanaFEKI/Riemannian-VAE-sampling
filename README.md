# Latent Space Oddity - Riemannian Geometry of VAE Latent Spaces
This project, developed for the Computational Statistics course, investigates the geometry of Variational Autoencoder (VAE) latent spaces by approximating the induced Riemannian metric using locally weighted importance sampling and RBF neural networks. It analyzes curvature and geodesics to understand how model variance shapes the latent-space structure.

**Original paper**: [Georgios Arvanitidis, Lars Kai Hansen & Søren Hauberg (2018). Latent Space Oddity: On the Curvature of Deep Generative Models.](https://arxiv.org/abs/1710.11379)
